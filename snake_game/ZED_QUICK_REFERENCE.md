# ⚡ Zed Rust 调试快速参考

## 🎯 立即开始

### 1. 打开 Zed 调试面板
**`Cmd + Shift + D`**

### 2. 设置断点
点击 `main.rs` 第2行行号 → 出现红点 🔴

### 3. 选择配置并启动
- 点击 ▶️ 或按 **F5**
- 选择 "Debug Current File"

## 🎮 调试控制

| 按键 | 功能 | 说明 |
|------|------|------|
| **F5** | 继续/开始 | 启动调试或继续执行到下一个断点 |
| **F10** | 单步跳过 | 执行当前行，不进入函数 |
| **F11** | 单步进入 | 进入函数内部 |
| **Shift + F11** | 单步跳出 | 跳出当前函数 |
| **Cmd + Shift + D** | 调试面板 | 打开/关闭调试面板 |

## 💡 实用调试技巧

### 设置条件断点
```rust
// 在第 19 行设置条件断点
for i in 0..100 {
    println!("{}", i);  // 条件：i == 50
}
```
**右键断点** → **Edit Breakpoint** → **条件：`i == 50`**

### 添加监视表达式
在 **WATCH** 部分：
- 点击 `+` 添加表达式
- 输入：`message.len()`
- 输入：`custom_num + hex_num`
- 输入：`&message` (查看地址)

### 调试控制台命令
```lldb
v message              # 查看变量
x/10x &message        # 查看内存
disas -c 5            # 查看汇编
bt                    # 调用堆栈
```

## 🎯 调试配置选择

### 推荐配置优先级：

1. **Debug Current File** ⭐ (最简单)
   - 自动编译和调试当前文件
   - 适合快速调试

2. **Debug Binary (main)** (稳定)
   - 使用 `cargo build` 的结果
   - 适合标准项目结构

3. **Debug with LLDB (Direct)** (高级)
   - 直接调试现有二进制
   - 适合分析已编译的程序

## 🔧 故障排除

| 问题 | 解决方案 |
|------|----------|
| 调试器无法启动 | `brew install llvm` |
| 断点不工作 | 使用 `cargo build` 而不是 `cargo build --release` |
| 变量显示 "optimized out" | 使用 debug 模式编译 |
| 找不到调试目标 | 运行 `cargo build` 先编译 |
